# وجداني — تطبيق العيادة

تطبيق سطح مكتب لليوم الطبي الكامل داخل العيادة، مصمم للأطباء والسكرتارية، ويعمل باللغة العربية بالكامل.

- الكشوفات والروشتات ونتائج التحاليل
- طابور الاستقبال وإدارة المواعيد
- المدفوعات والمبالغ المتبقية
- مساحات عمل مستقلة لكل دكتور
- مزامنة الصور السحابية بين الأجهزة

يعمل دون اتصال بالإنترنت أولاً، ويزامن تلقائيًا عند توفر الاتصال. صُنع للعيادات المصرية.

---

## English summary

Wijdani Clinic is a desktop app (Arabic UI) for doctors and receptionists: visits with prescriptions and lab results, a receptionist queue with appointments, payments with outstanding balances, per-doctor workspaces, and cloud photo sync. It works offline-first and syncs automatically when online.

هذا التطبيق واحد من تطبيقين لسطح المكتب يعملان على قاعدة بيانات واحدة، مع تطبيق الإدارة المخصص لأصحاب العيادات والمديرين.
This is one of two desktop apps sharing one database, alongside the Admin app for clinic owners and managers.
